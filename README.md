# Calculator

A calculator built with HTML, CSS, and JavaScript.

## How it works

This calculator implements Dijkstra's Shunting Yard algorithm to parse and evaluate mathematical expressions.

### Features

- Basic arithmetic operators
- Parentheses
- Decimal numbers
- Negative numbers
- Divide by zero error handling
